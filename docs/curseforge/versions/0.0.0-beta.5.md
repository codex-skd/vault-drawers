<h2>v0.0.0-beta.5 - Remove TOP/FTB integrations, add Jade module</h2>

<h3>Removed</h3>
<ul>
<li><strong>The One Probe</strong> integration — no build exists for Minecraft 26.2 / NeoForge 26.2.0.57.</li>
<li><strong>FTB Library, FTB Chunks, FTB Teams</strong> integrations — no builds exist for 26.2 (FTB ecosystem tops at 26.1.2.x).</li>
</ul>

<h3>Changed</h3>
<ul>
<li><strong>Jade integration</strong> (was WAILA/Jade in config) — renamed to <code>Jade</code> in config (<code>ModCommonConfig.INTEGRATION.jade</code>, <code>ModClientConfig.INTEGRATION.enableJade</code>). Added <code>JadeModule</code> to <code>LocalIntegrationRegistry</code> for automatic registration when Jade mod is loaded.</li>
<li><code>PersonalKeyRecipe.ftbEnabled()</code> now returns <code>false</code> (FTB Teams unavailable).</li>
<li><code>neoforge.mods.toml</code> dependencies updated: only <code>jei</code>, <code>jade</code>, and transitive <code>architectury</code> remain.</li>
<li>Project description updated: integrations list now shows only JEI and Jade.</li>
</ul>

<h3>Fixed</h3>
<ul>
<li><code>DrawerOverlay</code> and <code>Jade</code> classes now reference correct config paths.</li>
</ul>

<blockquote><strong>Note</strong>: The One Probe and FTB integrations were declared in mods.toml and config but had no compiled code for 26.2. They are removed until upstream builds become available.</blockquote>
