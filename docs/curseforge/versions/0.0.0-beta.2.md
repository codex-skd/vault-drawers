<h2>v0.0.0-beta.2 - Content and main class wiring</h2>

<h3>Added</h3>
<ul>
<li>All game assets and data ported from Storage Drawers 1.21.1: blockstates, models, textures, lang files, recipes, loot tables, tags, and advancements (1057 files, renamespaced to <code>vault_drawers</code>). The mod now has actual textures, translations, and crafting recipes instead of missing-texture placeholders.</li>
<li>Mod icon/logo (was missing in beta.1).</li>
</ul>

<h3>Fixed</h3>
<ul>
<li><strong>Critical</strong>: the mod's main class had all registry initialization commented out — it compiled but registered zero blocks, items, recipes, or capabilities at runtime. Fully wired now: config registration, block/item/block-entity/container/data-component/recipe registries, creative tab, capabilities, networking, and player event listeners.</li>
<li>Fixed several additional Minecraft 26.2 / NeoForge 26.2.0.57 API changes surfaced once the mod actually ran instead of just compiling: optional mod dependencies (JADE, The One Probe, Architectury, FTB integrations) no longer crash startup when absent; JEI dependency now resolves correctly; capability registration updated to the current NeoForge API; networking send-to-server call updated to its new location.</li>
</ul>

<blockquote><strong>Beta status</strong>: the mod now fully loads and registers its content (verified via automated data generation), but has not yet been tested with an actual running game client. Please report any issues you find.</blockquote>
