<h2>v0.0.0-beta.1 - Initial 26.2 port (beta)</h2>

<h3>Notes</h3>
<blockquote>First public beta of the port of Storage Drawers 13.11.4 from Minecraft 1.21.1 (NeoForge 21.1.196) to Minecraft 26.2 (NeoForge 26.2.0.57). Mod ID changed to <code>vault_drawers</code>. All original features are ported: storage drawers (1/2/4 compartments, full/half blocks, all wood types), trim system, upgrades (capacity, void, speed, redstone, magnet, remote, hopper, illumination, fill level, balance, conversion, portability, one stack, creative), controller network (up to 512 drawers), and JEI/JADE/The One Probe/FTB Chunks/FTB Teams integration.</blockquote>

<blockquote><strong>Beta status</strong>: the mod compiles and packages successfully after the full 26.2 API migration, but has not yet been verified in-game (client/server launch, block placement, upgrades, controller network). Please report any issues you find.</blockquote>

<hr>

<h3>Technical Changes</h3>
<ul>
<li>Package refactored to <code>com.stalkingdragons.minecraft.vaultdrawers</code> (was <code>com.jaquadro.minecraft.storagedrawers</code>).</li>
<li>Assets namespace changed from <code>storagedrawers:</code> to <code>vault_drawers:</code>.</li>
<li>Full migration to Minecraft 26.2 / NeoForge 26.2.0.57 APIs: <code>ItemStack</code> (de)serialization moved to Mojang Serialization <code>CODEC</code>s, <code>Item.appendHoverText</code>/<code>getName</code> signatures updated, <code>CompoundTag</code>/<code>ListTag</code> NBT reads updated to the new <code>Optional</code>-based accessors, <code>BlockEntityType</code> construction updated, and various renamed/relocated vanilla APIs fixed throughout.</li>
</ul>
