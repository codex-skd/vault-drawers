<h2>v0.0.0-beta.3 - Client crash fixed, first fully playable beta</h2>

<h3>Fixed</h3>
<ul>
<li><strong>Critical</strong>: the game client crashed on launch (<code>NullPointerException: Components not bound yet</code>) — <code>beta.2</code> never actually reached the main menu. Caused by constructing <code>ItemStack</code>s of vanilla items too early during mod loading; fixed by storing item references and building stacks lazily on first real use instead.</li>
<li>Fixed a capability registration ID collision that could crash capability setup.</li>
</ul>

<blockquote><strong>Verified</strong>: the mod now boots to the main menu and a singleplayer world loads and runs without crashing. Some minor cosmetic gaps remain (a handful of indicator/overlay block models and a few storage-upgrade item icons are missing textures) — these don't affect core functionality and will be polished in a future update.</blockquote>
