<h2>v0.0.0-beta.7 - Fix FerriteCore crash (root cause)</h2>

<h3>Fixed</h3>
<ul>
<li><strong>FerriteCore crash on startup</strong>: <code>IntegerSetProperty.getInternalIndex()</code> returned raw values (1,2,4) instead of sequential indices (0,1,2), causing <code>IllegalStateException</code> in FerriteCore's <code>FastMap</code>. Fixed to return proper sequential indices.</li>
<li><strong>Cascading unbound block crashes</strong>: The FerriteCore crash during block registration aborted the registration process before blocks like <code>keybutton_drawer</code> and <code>meta_indicator</code> were registered. This caused downstream <code>NullPointerException: Trying to access unbound value</code> in BlockItems and BlockEntityTypes. Fixing the root crash allows full block registration to complete.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>IntegerSetProperty.getInternalIndex(Integer value)</code> now returns <code>orderedValues.indexOf(value)</code> for FerriteCore FastMap compatibility.</li>
<li>Full block registration now completes, enabling dependent Items and BlockEntityTypes to resolve correctly.</li>
</ul>

<blockquote><strong>Note</strong>: The "unbound value" crashes for <code>keybutton_drawer</code> and <code>meta_indicator</code> were symptoms of the FerriteCore crash aborting block registration early. They are fixed by resolving the root cause.</blockquote>
