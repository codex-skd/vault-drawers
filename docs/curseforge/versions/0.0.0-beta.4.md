<h2>v0.0.0-beta.4 - Recipes and item icons fixed</h2>

<h3>Fixed</h3>
<ul>
<li><strong>All crafting recipes now work</strong>: the 1.21.1 recipe JSON format used by this mod is no longer accepted by Minecraft 26.2's recipe parser — every recipe silently failed to load in earlier betas. Converted all recipes to the current ingredient format.</li>
<li><strong>All items now show their correct icon</strong> in inventory/hand — Minecraft 26.2 requires a newer per-item "item definition" file that was missing for every item in the mod.</li>
</ul>

<blockquote><strong>Verified</strong>: launched a real game session with 0 recipe-parsing errors and 0 missing item icons.</blockquote>
