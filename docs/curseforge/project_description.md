<h1 align="center">🗃️ Vault Drawers</h1>

<p align="center"><strong>Interactive compartment storage for your workshops — NeoForge 26.2 port.</strong></p>

<br>

---

<br>

<h2>✨ Overview</h2>

<p>Vault Drawers is a port of the classic <strong>Storage Drawers</strong> mod to Minecraft 26.2 (NeoForge 26.2.0.57). It adds interactive, compartmentalized storage blocks that visually display their contents and upgrade over time.</p>

<p>Every drawer shows its stored items on the front face. Upgrade drawers with <strong>capacity upgrades</strong>, <strong>void upgrades</strong>, <strong>trim</strong>, and <strong>controllers</strong> to build massive, automated storage walls.</p>

<br>

<h2>🎯 Features</h2>

<h3>📦 Storage Drawers</h3>
<ul>
<li><strong>Basic Drawers</strong> — 1, 2, 4 compartment variants (Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Bamboo, Crimson, Warped)</li>
<li><strong>Full Blocks</strong> — 1, 2, 4 compartment full-block variants</li>
<li><strong>Half Blocks</strong> — Slab-height drawers for compact builds</li>
<li><strong>Trim</strong> — Decorative wood/metal trim variants</li>
</ul>

<h3>⬆️ Upgrades</h3>
<ul>
<li><strong>Capacity Upgrade</strong> — Increases stack limit per slot (up to 64x)</li>
<li><strong>Void Upgrade</strong> — Deletes excess items when full</li>
<li><strong>Speed Upgrade</strong> — Faster insertion/extraction rates</li>
<li><strong>Upgrade Slots</strong> — 1–4 slots depending on drawer tier</li>
</ul>

<h3>🎮 Controller System</h3>
<ul>
<li><strong>Controller</strong> — Central block linking up to 512 drawers via <strong>Controller Slaves</strong></li>
<li><strong>Controller Slave</strong> — Extends controller range</li>
<li><strong>Access via single block</strong> — Insert/extract from entire network</li>
<li><strong>Redstone modes</strong> — Disable, eject, round-robin, priority</li>
</ul>

<h3>🔧 Integration & Compat</h3>
<ul>
<li><strong>JEI</strong> — Recipe viewing for upgrades, trim, controllers</li>
<li><strong>JADE / The One Probe</strong> — Hover tooltips showing contents, upgrades, capacity</li>
<li><strong>FTB Chunks</strong> — Chunk claim integration (access control)</li>
<li><strong>FTB Teams</strong> — Team-based drawer access</li>
<li><strong>Architectury API</strong> — Cross-loader compatibility layer</li>
</ul>

<h3>⚙️ Configuration</h3>
<p>All drawer capacities, upgrade limits, controller range, and integration toggles are configurable via config file.</p>

<h2>🎮 How to Use</h2>

<ol>
<li>Install the mod (requires NeoForge 26.2.0.57+).</li>
<li>Craft drawers using vanilla wood planks + chest.</li>
<li>Place drawers — they face the player on placement.</li>
<li>Insert items: right-click with item in hand, or use hoppers/pipes.</li>
<li>Apply upgrades: right-click drawer with upgrade item.</li>
<li>Build a controller network: place Controller, link Slaves, connect drawers.</li>
</ol>
