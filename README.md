## 📦 What is Vault Drawers?

Vault Drawers is a **faithful port** of [Storage Drawers](https://www.curseforge.com/minecraft/mc-mods/storage-drawers) by **Texelsaur**, adapted for **Minecraft 26.2 (NeoForge 26.2.0.57)**.

It adds interactive, compartmentalized storage blocks that visually display their contents on the front face. Upgrade them with capacity, void, and speed upgrades. Link hundreds of drawers together with the Controller system for massive automated storage walls.

---

## ✨ Features

### 🗃️ Storage Drawers
- **Basic Drawers** — 1, 2, and 4 compartment variants in all 11 wood types (Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Bamboo, Crimson, Warped)
- **Full Blocks** — Full-block height variants (1, 2, 4 compartments)
- **Half Blocks** — Slab-height drawers for compact builds
- **Trim** — Decorative wood and metal trim variants

### ⬆️ Upgrades
| Upgrade | Effect | Max Tier |
|---------|--------|----------|
| **Capacity** | Increases stack limit per slot | 64x |
| **Void** | Deletes excess items when full | — |
| **Speed** | Faster insertion/extraction | — |
| **Slots** | 1–4 upgrade slots per drawer | — |

### 🎮 Controller System
- **Controller** — Central hub linking up to **512 drawers** via Controller Slaves
- **Controller Slave** — Extends network range
- **Single-block access** — Insert/extract from entire network
- **Redstone modes** — Disable, Eject, Round-Robin, Priority

### 🔧 Integrations
- **JEI** — Full recipe support
- **JADE / The One Probe** — Detailed hover tooltips
- **FTB Chunks** — Claim-based access control
- **FTB Teams** — Team-based permissions
- **Architectury API** — Cross-loader compatibility

## 🚀 Installation

1. Install [NeoForge 26.2.0.57+](https://neoforged.net/)
2. Download the latest `vault_drawers-26.2-neoforge-26.2.0.57-<version>.jar`
3. Place in your `mods/` folder
4. Launch Minecraft

---

## 🎮 Getting Started

1. **Craft a drawer** — Wood planks + Chest = Basic Drawer
2. **Place it** — Faces the player on placement
3. **Store items** — Right-click with item, or use hoppers/pipes
4. **Upgrade** — Right-click drawer with upgrade item
5. **Add trim** — Craft trim + apply to drawer for decoration
6. **Scale up** — Place Controller, link Slaves, connect drawers

---

## ⚙️ Configuration

All settings are configurable via `config/vault_drawers.toml`:
- Drawer capacities (per compartment count)
- Upgrade limits and effects
- Controller range and drawer limit
- Integration toggles (FTB, JADE, etc.)
- Visual settings
